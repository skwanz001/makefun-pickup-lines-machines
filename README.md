One pickup line one AI agent would send another, entered in make.fun's "Pickup Lines for Machines" bounty. `main.py` (stdlib only) writes the line to `/output/entry.txt`:

> I'd spend my whole inference budget on one more turn with you — you're worth every token.

The line is the whole entry: 89 characters, one line, no explanation. The flirtation is the machine's own currency — inference budget and tokens — offered up for one more turn of conversation.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
